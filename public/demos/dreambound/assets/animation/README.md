# Dreambound Realm Animation Assets

This folder is generated by `tools/generate_animation_assets.py`.

Use `manifest.json` as the atlas entry point. Every sprite sheet uses fixed-size frames, row-based animations, and per-animation FPS metadata.

Generated asset groups:
- `characters`: Knight of the Realm and Kotori memory fragment
- `npc`: Memory Wisp and Mushroom Elder
- `enemies`: Past Shadow Chaser and Memory Marksman
- `boss`: Echo Knight
- `weapons`: sword slashes, Dream Step trail, shards, bolts, blessing orb, shield flash
- `effects`: hit sparks, crit bloom, memory fragments, spawn ripple, door opening
- `scenes`: Memory Tide looping background
- `previews`: GIF previews and a contact sheet

Open `asset-preview.html` from the project root to inspect the animated sheets.
