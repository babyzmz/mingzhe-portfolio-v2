# Image 2 Fine Assets

This folder contains high-detail raster assets generated from the project setting documents for `Dreambound Realm`, focused on Chapter I: `Memory Tide`.

Setting basis:
- Dreambound is a shared unconscious dream dimension.
- Chapter I is Memory Tide: broken memory glass, reversed images, warped ruins, past shadows.
- The player is the Knight of the Realm, based on the BB knight reference.
- Kotori is a dream-weaving princess/memory fragment.
- Echo Knight is the first chapter boss, a regret mirror of the knight's failed protection.
- Early BB/Kappa/Dark Lord files are used as visual motifs.

Files:
- `memory_tide_asset_sheet_v1.png`: full generated high-detail concept sheet.
- `manifest.json`: crop manifest for individual assets.
- `crops/*.png`: individual character, NPC, enemy, weapon, VFX, and scene crops.
- `image2_asset_contact_sheet.png`: quick visual contact sheet.

Generation note:
- Local CLI `gpt-image-2` was requested, but this workspace does not have `OPENAI_API_KEY` set.
- ChatGPT Pro subscription access is not a local API credential. The CLI path requires an API key in the environment.
- The current sheet was generated through the available built-in image generation path and then copied into this project.
