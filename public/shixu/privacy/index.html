隐私与数据说明

更新于 2026 年 10 月 15 日

本机保存

桌面事项保存在当前 Windows 用户的本地数据库；网页事项保存在当前浏览器的本地存储。普通事项数据库与浏览器记录不是全盘加密。公共电脑使用后请退出账户，必要时清除本站数据；清除前先确认同步成功或导出备份。

账户与云端同步

登录后，事项、分类与事项模板在设备上使用 AES-256-GCM 加密，再通过 HTTPS 发送至 Cloudflare Worker，并以密文保存至 D1。服务保存用户名、加盐验证信息、加密的数据密钥、会话及必要的版本信息，不接收明文密码或原始数据密钥。

窗口配置、系统提醒状态、助手聊天和模型 API Key 不参与事项同步。退出登录会撤销当前会话，其他设备不会自动退出；修改密码会使其他会话失效。账户的本机缓存会保留，以便下次登录继续，退出并不删除云端记录。

密码与找回

设备通过密码派生密钥保护数据密钥。修改密码需要验证旧密码，并重新保护同一份数据密钥，已有记录不受影响。目前不提供恢复码、密码找回或第三方登录，忘记密码后无法自助恢复加密记录。

模型数据发送

只有启用桌面云模型并发起助手请求时，相关事项、提问和必要对话上下文才会发送至你选择的模型服务商。模型提供方的保存、训练与收费政策以其说明为准。网页本地规则助手不向模型服务发送事项。

网站、更新与服务日志

官网与网页由 GitHub Pages 托管，域名 DNS 由 Cloudflare 管理，Windows 更新包由 Cloudflare R2 提供。访问这些服务会产生常规网络信息，例如 IP、请求路径和时间；身份与同步接口响应不进入网页离线缓存。应用不发布用户记录、API Key 或聊天到公开仓库。

备份与联系

你可以在设置中导出与导入 JSON 备份，备份包含事项明文，请自行妥善保管。若需要协助清除云端测试账户，请联系维护者；目前没有自助账户删除入口。

安卓后台日历连接

只有主动开启锁屏实时同步时，设备才建立带账户认证的持续连接。云端只发送不含正文的变更信号；日程密文在设备本地解密后写入独立的拾序系统日历。日历数据库由手机系统管理，系统日历中的记录不属于云端加密存储，手机日历应用和获得日历权限的应用可能读取这些记录。

为锁屏同步，账户会话和数据密钥通过 Android Keystore 的 AES-GCM 密钥保护后留在设备，关闭后台同步或退出登录会清除这份后台凭据。日历方向为拾序到手机，不读取其他日历内容。连接使用网络和少量电量；同步期间短时使用带超时的唤醒锁，无永久唤醒锁。
