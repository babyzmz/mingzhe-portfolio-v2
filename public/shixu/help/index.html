使用帮助

安装与更新

下载 Windows x64 压缩包，解压全部文件到固定文件夹，运行 Shixu.exe。不要在压缩包内启动。设置中的“检测更新”会检查签名清单，下载后验证完整性，再安装更新。

下载 Windows 版 ↗

登录与同步

在网页或桌面工作台左下角点击“登录账户”，注册 Fairy 账户，再在另一端登录相同用户名与密码。首次登录会把当前本机事项与分类加入同步。修改密码需要先登录并输入旧密码；暂不提供找回密码功能，请妥善保管。

退出账户会隐藏该账户的本机记录，登录同一账户后恢复。切换账户时不会合并上一位用户的记录。发现同一记录被两端同时修改时会暂停同步，先导出备份，再选择保留版本。

打开工作台 ↗

旧地址与旧同步迁移

旧 GitHub 地址的浏览器数据无法被新域名直接读取。先在旧网页工作台登录账户并完成同步，再到新域名登录同一账户；还未同步的记录可导出 JSON 后在新网页导入。已使用旧同步的设备，请先更新桌面端，在该设备注册时会自动迁移旧同步记录，不再需要配对码。

打开旧网页工作台 ↗

桌面组件与侧栏

桌面端可把待办、日程或便签拖出为组件，也可加入已有组件。组件的大部分空白区域可拖动；按钮、输入框与滚动内容保留各自的操作。右上角助手按钮打开侧栏，页面会为它留出位置；进入全局助手页面会关闭侧栏。

网页和 Android 不创建 Windows 桌面组件；桌面标签、托盘和原生窗口操作请使用 Windows 版。

提醒

在编辑事项中选择提醒日期与时间。桌面端需要应用或托盘保持运行；完全退出后不会触发提醒。网页需要页面打开并获得通知权限，浏览器关闭后不保证提醒。请确认电脑时区和系统通知设置。

AI 配置

桌面设置中填写自己的模型服务地址、模型 ID 和 API Key。推荐使用硅基流动的 deepseek-ai/DeepSeek-V4.1-Flash（三端统一）。已使用旧版硅基流动 GLM 的配置会迁移，其他自选服务保留。桌面密钥仍由本机保管；实际模型可用性、余额和计费以服务商为准。密钥保存在本机，不会随账户同步。

云模型开启后，助手按需要读取相关事项并发送给所选服务商。待办拆解、日程安排和组件操作先生成提案，确认后执行。网页与 Android 小拾登录后可使用硅基流动 DeepSeek V4.1 Flash。密钥只保存在服务端，不需要用户填写；首次提问前会询问是否发送相关事项和对话。输入框内可以切换本机查询，设置中可以撤销授权。新增、改期、完成、分类和模板操作先显示确认卡片，点击后才执行；记录变化后会要求重新生成，避免覆盖。

每天多次记录

在首页点击右上角加号，新建待办后选择“每天记录”，填写标题或备注，设置每天的目标次数。无需设置开始、结束或计时。事项上的加号直接记录当前完成时间；点击“查看记录”可补记时间、添加备注或撤销某次记录。每天的次数按查看设备的本地日期计算；达到目标后仍能继续记录，不自动删除事项。普通待办仍可直接勾选完成。

日程可选择“单个时间点”或时间段。单时间点显示一个时刻；为兼容手机系统日历，内部使用一分钟的日历占位，不要求实际执行满一分钟。

请先更新 Windows 0.4.17、Android 0.1.4，再使用新版网页工作台；旧桌面客户端遇到新记录格式会暂停同步，原数据保留。

安卓锁屏实时同步

安装 Android 0.1.4 后登录同一账户，在设置中连接手机日历，再开启锁屏实时同步。允许通知、不受电池优化限制及厂商要求的自启动。应用显示常驻同步通知，可随时停止；断线后自动退避重连并低频补查。

实际手机仍需验证。强行停止、断网、未授权后台运行或会话过期会影响及时性。后台有未上传修改或冲突时暂停，先打开拾序处理。系统日历内的编辑暂不回传。

受控下载与旧版迁移

下载和更新已接入 updates.fairyllm.com，旧的公开 R2 地址已关闭。无法访问旧服务地址的用户，请从下载页手动安装新版。下载达到防刷预算后会暂时停止，请稍后再试。

简洁新建与常用模板

标题和备注填写一项即可保存，计划执行日期默认留空。日期、提醒和更多设置按需展开；选择今天、明天或周末是明确设置日期，不会自动替你安排。输入明确时间语句后，可先查看识别结果，再点击应用，未应用时不会写入日期。

待办分为一次性、重复待办和每天记录。每天记录设置目标次数，提醒时段单独添加；早晚各一次会填入09:00与21:00，可用滚轮修改。重复待办完成后才生成下一次，可以选择星期或间隔、结束日期，保存前查看下次日期。

更多设置中可以保存模板、套用模板或复制新建。新事项会清空完成记录和子任务勾选；复制保留日期，模板则将日期整体移到今天，保存前请检查。勾选连续添加后，保存会直接打开下一条新事项。

多个提醒与设备更新

每条事项最多设置10个提醒。新建每天记录时，不会补发创建前已过去的每日时段。网页需要保持打开；Windows应用完全退出或电脑休眠会影响提醒；安卓需允许通知，精确闹钟未授权时提醒可能延迟。手机最多安排最近200个本地提醒，触发后继续补齐后续提醒。强行停止应用仍可能中断提醒。

使用模板、多时段提醒和自定义重复前，请更新 Windows 0.4.22、Android 0.1.11，并刷新网页。新数据使用旧客户端无法读取的同步格式，以保护新增设置；旧客户端出现格式提示时应升级，不要用旧备份覆盖云端。

工作台 V2 的入口

桌面工作台左侧保留五项主导航，专注与回顾在更多工具中。手机底部依次为今天、事项、新建、日历、更多；收集箱、便签、分类管理、助手、搜索、设置与账户在更多中。新建按钮会打开编辑面板，待办可以选择一次性、重复待办或每天记录。外观在设置中选择跟随系统、浅色或深色。

标题与备注填一项即可。计划执行日期默认留空，与截止日期分别保存。网页组件预览已移除，Windows 原生组件继续在 Windows 应用中使用。

Android 应用内更新

首次从下载页安装 0.2.8 或更新版本。之后打开更多 → 设置 → 关于拾序 → 检查更新。发现新版后下载；首次安装更新需要允许拾序安装应用，返回后点安装更新，并在系统界面确认。无需卸载旧版，卸载会删除未同步的本机记录。

下载支持取消；只在用户点击时下载，启动检查有频率限制。下载或校验失败不会自动安装，也不会反复下载。应用内仅接受经过签名且与当前应用同签名的更新包。
