Mojo product family · by OpenAX

Two workbenches.One authority.

MojoClaw is for individuals; MojoAX is for teams. Both run on Mojo Core, which owns models, permissions and run state so the apps can stay honest about what happened.

Personal AI workbench · Web and Mac desktop

MojoClaw

MojoClaw is a personal AI workbench on the web and the Mac desktop. Chats can become cloud projects or work inside a folder on your computer, and every result stays something you can open, preview and undo.

Running in the dev buildRead more ↗Shared authority · Gateway, runs, models, permissions

Mojo Core

Mojo Core is the shared authority behind MojoClaw and MojoAX. Identity, projects, runs, model routing, permissions, memory and the usage ledger live in Core; the product apps render its facts and forward your decisions.

MojoAX

MojoAX is the enterprise sibling of MojoClaw: a workbench where the task in progress summons the surface it needs, with governance for teams. It is developed after MojoClaw and Mojo Core, so this page separates what exists in source from what is planned.
