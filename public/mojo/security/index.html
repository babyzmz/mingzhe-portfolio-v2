Privacy & safety

Strict, with few interruptions.

Security may be strict, but confirmations must be rare. Every feature is designed against a confirmation budget: work inside the project proceeds on its own, and crossing a boundary asks once for that scope.

MojoClaw

Local stays local

Bound-folder files are read on the device. With the strict local data policy, Core receives digests instead of content, and a local tool is never moved to the cloud to finish a task.

A sandbox that does not quietly give up

"Work inside the project" edits only that folder; commands run in the native macOS sandbox with the network off by default. A sandbox failure stops the step rather than running it unsandboxed.

A confirmation budget

Inside the project nothing asks. Crossing a boundary — a new folder, outbound data, a dangerous tool — asks once, and the answer covers that scope.

Remote control per thread

Each thread starts with remote control off. Only the computer where the thread lives can turn it on or widen it; the web can use it, not change it.

Memory you can see

Memories are stored by Core, listed with their source chat, and can be deleted or switched off. Suggested memories wait for your confirmation.

Mojo Core

Identity from the session only

Self-asserted identity headers are rejected; tenant and actor come from the authenticated session.

Grants bound to scope

Approval covers a named server, account, tool set, data scope and side effects. Wider scope asks again; the same scope does not.

No silent fallback

An offline device makes its tools unavailable. Core does not reroute local material through the cloud to finish a task.

Measured, not assumed

Cache savings and costs are reported from provider usage fields per call, with unknowns recorded as unknown.

History is append-only

Published migrations are never edited; rollbacks are new migrations.

MojoAX

Same authority as MojoClaw

Identity, tenant and permissions come from Core sessions, not from the client.

Nothing claimed beyond the last review

Scaffolds, unverified integrations and roadmap items are not described as delivered.
