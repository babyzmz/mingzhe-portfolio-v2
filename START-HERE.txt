MINGZHE — SYSTEMS IN MOTION · v2.1

本次更新：项目展开动画 + 九个项目中英文详细介绍

1. 解压整个工程包。
2. 用 Chrome 或 Edge 打开根目录 Mingzhe-Portfolio-Preview.html。
3. 从“深入了解项目”或“全部项目”的任意卡片进入详情。
4. 留意展开、关闭、章节滚动、下一项目、术语折叠的真实动画。
5. 详情顶栏可中英文切换、上/下一项目；关闭后回到原位置。

若电脑开启“减少动态效果”，或网站右下角关闭动画，详情将按设置减少动画。
请不要误开上次下载的旧版 HTML。

单文件无需安装依赖，无需 API 密钥。外部 GitHub 链接需要联网。
